# 漢方診療チュートリアル ― 医療面接から方剤選択まで

初期研修医を対象に、**問診 → 四診 → 証の組み立て（気血水・八綱・六病位・五臓）→ 方剤選択** という漢方診療の流れを、症例ベースで体験できるブラウザ学習ツールです。単一の HTML ファイルで動作し、外部サーバーやインストールは不要です。

## 特長

- **全35症例**：感冒・消化器・精神/不眠・婦人・腎虚・呼吸器・皮膚・外傷など、初期研修で出会いやすい主訴と頻用方剤を網羅。
- **インタラクティブ**：選択肢ごとにフィードバックが出て、間違えても先に進めます。
- **四診の図**：症例ごとに変化する舌診・腹診の SVG 図。
- **生薬構成図**：正解方剤の構成生薬を働き別（補気・補血・利水・温陽・清熱…）に色分け表示。
- **古典の出典と記載**：各方剤の出典（傷寒論・金匱要略・和剤局方ほか）と原文、〔大意〕、〔現代風の説明〕。
- **学習の記録と成長**：症例ごとの最高スコア、習熟度マップ（軸ごとに正答で育つ段階・星）、称号バッジの収集、修了証。記録はブラウザ（localStorage）に保存されます。

## 使い方

公開後は、GitHub Pages の URL にアクセスするだけで利用できます（インストール不要）。
ローカルで開く場合は、`kampo_tutorial.html` をブラウザでダブルクリックして開いてください。

## ファイル構成

- `kampo_tutorial.html` … 学習ツール本体（これ1つで完結）
- `index.html` … トップページ（本体へ自動リダイレクト）
- `README.md` … 本ファイル
